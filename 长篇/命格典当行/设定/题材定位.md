# 题材定位

## 基本信息
- 书名：命格典当行（暂定）
- 题材/类型：都市异能 + 系统流 + 单元逆袭（主类型：都市异能；副类型：轻悬疑/单元剧）
- 目标平台：番茄小说 / 起点中文网
- 预计字数：120 万字
- 目标读者：18-35 岁男性为主，兼顾喜欢「单元故事 + 主线揭秘」的女性读者
- 主对标书：无（本项目暂未做拆文，按八节点占比自排节奏）

## 一句话梗概
失业青年陆时继承爷爷留下的旧当铺，激活了能典当他人「气运与命格」的系统，从帮第一个走投无路的客人翻盘开始，一步步揭开当铺连接阴阳两界的秘密，也重塑自己一败涂地的人生。

## 题材核心梗（三分法）
- **爽点内核**：主角掌握「看得见别人命格、并能交易命运」的信息碾压。别人看不见的东西，他一眼看穿；别人无解的死局，他一笔勾销。爽在「掌控感」与「打脸暴发」。
- **情绪引擎**：单元制客人 = 每 3-5 章一个完整的小故事（一个走投无路的人 + 一次翻盘 + 一次打脸）。读者的期待感来自「下一个走进当铺的人会带来什么故事」。
- **差异化**：市面同类多是「主角自己变强打怪」，本书把金手指做成「服务型」——主角靠帮别人改命来给自己攒积分、升级当铺，客人的故事同时是主线线索。冷门切口：当铺不收金银，只收「气运、情绪、记忆、寿数」。

## 核心冲突
- **主线矛盾**：陆时想弄清爷爷失踪的真相与当铺的来历；而当铺的「上级」（阴阳交易的规则制定者）并不希望这个秘密被一个新人触碰。
- **终极阻碍**：掌控人间气运流通的幕后组织「司命台」，以及陆时自己签下的第一张、连他都不知道代价的「本命当票」。

# 回光与究死之法（力量体系 / 金手指）

## 定位
本书破案以「验尸 + 江湖信息差」为骨，金手指「回光」只提供方向，不替代证据。这样保留《非自然死亡》式的专业推理质感，又给悬疑留一个会骗人的变量。

## 金手指：回光
- 持有者：温故（一脉单传，师父秦究传下）。
- 能力：净手验尸、以指按住死者眼睑时，能读到死者**睁眼看到的最后一幕残像**——只有一瞬，画面模糊，像隔着雨看灯。
- 关键限制（决定它不破坏推理）：
  1. **只有一瞬、只是所见**：死者最后看到的，未必是凶手，也可能是天花板、是一只手、是一个背影。它给线索，不给答案。
  2. **会骗人**：凶手若刻意让死者临终看向别处，残像就是误导。温故必须用证据反证残像。
  3. **有代价**：每读一次，心神耗损，耳鸣、目眩、当日难以再用；重伤或死太久的尸体读不到。
  4. **不可言说**：温故从不对外说这本事的来历，对团队只说"我看得出来"。

## 究死之法（真正破案的手段）
1. **验**：尸斑、僵直、七窍、指甲、口鼻、伤口有无、毒物气味——以物证判断死亡时间与方式。
2. **访**：贾平安的江湖小道消息 + 团队走访，补齐死者生前最后的行迹。
3. **推**：把残像、物证、行迹三者对上；三者相互矛盾时，以物证为准，残像作废。
4. **证**：还原现场、请君入瓮，逼真凶自曝或留下铁证。

## 反派手法（主线）
- 「摆渡人」擅长制造"无痕之死"：让死者看起来死于走火入魔、失足、殉情、暴病。他懂医、懂毒、懂人心，专钻"江湖不愿深查"的空子。
- 每破一桩伪装成意外的命案，就离这个人近一步。

# 题材定位

## 基本信息
- 书名：究死客栈（暂定）
- 题材/类型：武侠悬疑 + 单元探案（主类型：江湖武侠；副类型：悬疑推理 / 轻喜剧 / 细思极恐）
- 参考调性：日剧《非自然死亡》（UDI 究明不自然死亡）的江湖化——冷静专业的验尸团队 + 每集一桩被草草定性的死亡 + 社会性痛点 + 一条贯穿全篇的连环命案主线。
- 目标平台：起点中文网 / 番茄小说
- 预计字数：100 万字
- 目标读者：喜欢《非自然死亡》《唐人街探案》《大宋提刑官》的读者；吃"专业查案 + 团队群像 + 反转揭底"的人群。

## 一句话梗概
江湖上死得不明不白、无人认领的尸身，会被送到一家只收死人的"究死客栈"；年轻掌柜温故凭一手验尸与能读到死者最后一眼残像的"回光"，带着一群各有秘密的伙计，替死者查明真正死因，一桩桩单元奇案背后，浮出一个把杀人伪装成天意的"摆渡人"。

## 五味基调架构（防串味）
分层不混拍，同一拍不同时上喜剧和恐怖。
| 元素 | 职责 | 出现在哪 |
|------|------|----------|
| 轻松喜剧 | 追读粘性、降门槛 | 过程：团队日常、贾平安贫嘴、拌嘴 |
| 武打 | 高潮爽感 | 案件收尾的动作戏，由护院秦缺承担 |
| 江湖 | 世界观容器 | 门派/镖局/规矩，提供奇案素材 |
| 悬疑 | 结构骨架 | 单元案 + 主线，验尸证据 + 信息差驱动 |
| 细思极恐 | 后劲、记忆点 | 揭底最后一击：定性为意外的，其实是系统性的恶 |

口诀：**笑点在前，寒意在后**。每个单元 = 喜剧糖衣 + 细思极恐内核。

## 题材核心梗（三分法）
- **爽点内核**：为死者翻案的"最后代言人"。所有人都说是意外，只有究死客栈说不是，并把真相一寸寸挖出来——爽在"替沉默的死者出一口气"。
- **情绪引擎**：单元制。每 3-5 章一具"被定性为意外/自尽/走火入魔"的尸体上门，团队究出被掩盖的真相。期待感来自"下一具尸体藏着什么"。
- **差异化**：市面武侠多写活人比武争锋，本书写"死人"——以验尸推理为骨、江湖为壳、《非自然死亡》式社会痛点为魂。金手指"回光"提供悬疑误导与记忆点，但破案仍靠证据。

## 核心冲突
- **主线矛盾**：温故要查清师父当年"走火入魔而死"的旧案；线索指向一个把无数命案伪装成天意的无痕杀人者「摆渡人」。
- **终极阻碍**：摆渡人，以及维护江湖"体面"、宁可让死者背锅也不愿真相出土的各大门派与官府。

## 灵魂金句
「在这条江湖上，没人该死得不明不白。」

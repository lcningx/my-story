# 《红线刀》设定

## 短篇核心框架

### 基本信息
- 标题：红线刀
- 目标字数：10000 字（8000-12000）
- 目标平台：番茄 / 七猫短篇（古言江湖向）
- 情绪目标：意难平（相爱却隔着世仇，刀落时爱与恨一并碎）
- 题材方向：江湖世仇 × 相爱相杀（冷门题材：情感/虐心骨架 + 古言简洁设定；腔调半文半白江湖口吻）
- 叙述视角：第一人称「我」（女主沈棠）
- 小节标记：`###1.` / `###2.` …
- 对话引号：半角双引号 `""`
- 写法偏好：少台词，多打斗；关键信息靠动作、信物、血书/物证推进

### 一句话梗概
我奉命刺杀陆家少主，却在刀抵他心口时发现自己爱上了他；世仇逼我们互刃，真相揭开时才知：我身上流着两家的血，而他用命替我挡了本该落在我身上的那一刀。

### 核心反转
- 反转类型：身份反转 + 动机反转
- 反转内容：
  1. 「我」沈棠之母本是陆家嫡女，因私定终身被两家追杀，临死把我托给沈家；我是世仇里唯一的「双姓血脉」
  2. 陆辞早知我身份，不杀我是因母命「护棠」；他接近我、被刺、护我，全是在渡我这一劫
- 误导假线索：陆辞杀了我爹沈铮；陆家要灭沈家满门；陆辞温言软语只为套取沈家刀谱
- 铺垫真线索（≥3）：
  1. 陆辞从不伤我要害，对战只卸力、只护、只挡
  2. 我左腕胎记与陆家「红线刀」刀柄刻纹同源
  3. 陆辞怀里藏着半块玉佩，背面刻「棠」字，与我亡母遗物拼得上
  4. 旁人细述「沈陆火并夜」细节时，我会偏头痛、耳鸣（血脉共鸣/幼时目睹）

### 情绪设计
- 开头情绪：杀意与心跳并置（强度 8）——刀抵心口，手却软
- 中段情绪：相爱拉扯 + 两家逼杀（强度 5→8）
- 反转情绪：身份砸下，爱恨同根（强度 10，峰值第 9-10 节）
- 结尾情绪：意难平余韵（强度 8→6）——红线断在刀上，人各一方
- 节奏：暖（私会）→ 残忍（世仇逼杀）→ 善意（他护我）→ 真相 → 来不及 → 物件余韵

### 人设速写
- 女主（沈棠）：沈家唯一嫡女，刀快、恨硬、心里却藏着不该有的软；奉父遗命杀陆辞；实不知自己有半身陆家血
- 男主（陆辞）：陆家少主，外冷内热，刀稳话少；早知沈棠身份，宁背「软蛋」「护仇」骂名也要护她活
- 关系：仇家 → 私订 → 刀下爱人 → 真相后生死错位
- 配角：
  - 沈烈：沈家二叔，主战派，逼沈棠当众斩陆辞
  - 陆铮：陆家长老，主灭沈，逼陆辞大义灭亲
  - 阿芽：沈棠贴身丫鬟，知部分旧事，关键时递信物

### 反派 / 压力源
- 真正的「恶」是世仇本身 + 两家主战派：
  - 沈烈：嚣张型，小恶嘲讽 → 中恶当众逼杀 → 大恶要以陆辞人头祭旗
  - 陆铮：冷血型，以门规压陆辞，必要时亲自动手斩「双姓孽种」
- 报应：火并中主战派互斩殆尽；世仇烧尽，却也烧尽能成全他们的人

### 揭露方式
- 主用：证物揭露（玉佩合璧 + 亡母血书）+ 证人（阿芽递出藏多年的信）
- 辅用：延迟剥洋葱
  - 第 1 层（第 8 节）：陆辞未杀沈铮（假线索崩）
  - 第 2 层（第 9 节）：我有陆家血脉，胎记=刀纹
  - 第 3 层（第 10 节）：母命「护棠」；陆辞用命兑现

### 题材招式（本篇选用）
- 情感/虐心：前 1/3 用私会、替伤、共握刀建羁绊
- 古言简洁：两家恩怨一笔带清，不铺大世界观
- 相爱相杀：刀抵心口仍吻/仍护，动作代替告白
- 开篇钩子：冲突前置（刺杀当场，手软）
- 结尾：余韵式 + 红线刀回扣
- **少台词多打斗**：对白只留刀口边的短句；两家火并、私斗、劫场用动作推进

### 对标摘要
- 无对标拆文；按情感/虐心 + 江湖世仇自建。

### 反转信息差验证
- 真相主揭示节：第 9 节；总节数 12；位置 ≈ 75%（>60%，合格）
- 假线索（陆辞杀父）贯穿前 7 节；第 8 节崩角
- 真线索分散：第 1/3/5/6 节；与揭穿间距 ≥ 3 节

### 伏笔回查
- 结尾元素：红线刀、玉佩合璧、陆辞之死或重伤、沈棠独活/远走
- 铺垫：胎记(1) / 玉佩(3) / 他不伤要害(2,5) / 头痛(4) / 「护棠」(9)
- 贯穿道具三次出现：红线刀 1→9→12；玉佩 3→9→12

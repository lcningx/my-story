# 《夜读聊斋》设定

## 短篇核心框架

### 基本信息
- 标题：夜读聊斋
- 目标字数：10000 字（8000-12000）
- 目标平台：番茄 / 七猫 / 黑岩短篇（现代悬疑向）
- 情绪目标：细思极恐（读完后背发凉）+ 轻意难平（真相不可回头）
- 题材方向：现代都市悬疑 × 聊斋志怪（冷门融合：悬疑公式 + 聊斋母题「画皮 / 香火 / 录怪」）
- 叙述视角：第一人称「我」（女主沈昼）
- 小节标记：`###1.` / `###2.` …
- 对话引号：半角双引号 `""`
- 写法偏好：少对白、多动作与信息差；女主清醒会查证；爱意若有则不言破；**女主声线=吐槽役**（内心吐槽密、嘴上可冷可损，惊吓后先损一句再办事）

### 一句话梗概
我靠午夜直播《聊斋》谋生，神秘观众每点一篇，城里就按篇目死一个人；查到最后才发现——我读的不是故事，是放怪的咒，而我自己，才是书里那张还没画完的皮。

| 香火与听书 | 直播打赏 = 香火；弹幕 = 愿 |

| 城隍夜巡 | 城市监控盲区、「夜班城管」实为收容编制 |

### 核心反转
- 反转类型：认知反转 + 身份反转（嵌套）
- 反转内容：
  1. 「模仿聊斋杀人」是假线索；死者是被启封的志怪回收失败
  2. 室友陆朗不是凶手，是被我启封后「暂借人皮」的画皮残魄，靠我活着
  3. 峰值：沈昼本是旧时录怪笔吏的转生容器；直播间是新庙；「青凤」是监约狐，逼她读完最后一篇《画皮》以封库——读完则她现原形
- 误导假线索：连环杀手按书作案；陆朗行踪诡异必是凶手；平台要封杀灵异直播
- 铺垫真线索（≥3）：
  1. 我念到「血」字时，麦克风总会爆一段不是我的呼吸
  2. 陆朗从不入镜、不照镜子，却把我的粉底与美颜参数记得死紧
  3. 打赏「青凤」的金额永远是 8.88 / 16.66，对应旧时香烛数
  4. 我左手虎口有墨痣，越播越深，像笔尖印

### 情绪设计
- 开头情绪：诡异好奇（强度 7）——弹幕点名，隔壁就响
- 中段情绪：追查压迫（强度 6→8）
- 反转情绪：细思极恐峰值（强度 10，第 9-10 节维持）
- 结尾情绪：余寒（强度 7→5）——关播，灯亮，皮还在
- 节奏：怪事 → 查证 → 误判室友 → 真相分层 → 自己才是库门

### 人设速写
- 女主（沈昼）：**吐槽人设** + 清醒惜命会取证；靠夜读聊斋赚生活费；不信邪却必须靠「邪」吃饭
- 关键（陆朗）：合租室友，话少、体贴、行踪飘；实为画皮残魄，爱藏在「替她挡镜头 / 替她收尸气」的动作里，不言破；常被沈昼单方面吐槽「人形加湿器 / 行走美颜插件」
- 青凤：打赏ID，监约者；弹幕冷、准，从不表白意图；沈昼私下称「八块八冤种」「狐狐催更役」
- 配角：片警周叔（知一点旧事欲言又止）；运营小唐（催数据，专供吐槽）

### 女主声线：吐槽役（正文硬约束）
- **内核**：怕归怕、查归查，嘴和脑子先损为敬。细思极恐靠信息差，不靠她吓傻尖叫。
- **吐槽对象优先级**：
  1. 自己（穷、社畜、靠念鬼故事交租）
  2. 规则/青凤/平台（香火资本主义、催更比索命狠）
  3. 陆朗（安静、不照镜、过分能干——损里藏在意）
  4. 小唐/围观（流量邪教）
- **句式习惯**：短句阴阳；先结论后补刀；惊悚现场也来一句冷的，再动手取证。例：「很好，蒲松龄上班，我加班。」「隔壁按书死法打卡了，五星好评。」
- **禁区**：
  - 不靠连篇脏话撑人设；损要准，不贫到消戏
  - 反转峰值（现皮/镜中无脸）吐槽骤减，改短、改冷，留恐惧
  - 对陆朗的真在意不说破，只允许「损他」当遮羞布
- **与少台词兼容**：吐槽主要走**内心独白/旁白腔**，对外仍话少；关键对白可带刺，但不吵不辩经

### 反派 / 压力源
- 表层压力：命案逼近、平台警告、警察约谈
- 深层压力：香火契约——不读则饿死（无打赏），读则放怪
- 陆朗非传统反派；真正的冷酷是「规则」本身（青凤 / 库）

### 揭露方式
- 延迟剥洋葱 + 证物（录音频谱、美颜工程文件、未播完整轨）
- 第 8 节崩假线索（陆朗不是凶手）
- 第 9 节身份合页（录怪笔吏）
- 第 10 节现皮（镜子）

### 题材招式
- 悬疑：信息差、排除法、每 2-3 节钩子
- 聊斋：志怪规则冷酷，报应不讲情
- 女主清醒：先取证再下判，不因惊吓变蠢
- 吐槽役：用冷幽默托住现代感，惊悚段落「损一句→立刻做事」，不把恐怖写成段子合集
- 爱在不言中：陆朗的护与守全靠动作；沈昼用吐槽当盾，双方不说爱

### 对标摘要
- 无拆文对标；聊斋取《画皮》《聂小倩》《青凤》意象重组，不复述原著情节。

### 反转信息差验证
- 主揭示第 9 节 / 共 12 节 ≈ 75%
- 假线索（陆朗是凶手）第 7 加固、第 8 崩
- 真线索分散于 1/2/4/6，间距合格

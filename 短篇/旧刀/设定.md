# 《旧刀》设定

## 短篇核心框架

### 基本信息
- 标题：旧刀
- 目标字数：10000 字（8000-12000）
- 目标平台：番茄 / 七猫短篇（古言武侠向）
- 情绪目标：意难平（追杀十年，刀落时恨错了人，也恨晚了）
- 题材方向：江湖恩怨 × 宿命（冷门题材，用 `genre-writing-formulas.md` 情感/虐心骨架 + 古言简洁设定；腔调走短篇通用底座 + 半文半白江湖口吻）
- 叙述视角：第一人称「我」
- 小节标记：`###1.` / `###2.` …
- 对话引号：半角双引号 `""`

### 一句话梗概
我追杀「屠门仇人」十年，刀抵他咽喉时才知：那夜屠尽我家的是中了迷药的我自己，他替我背了十年骂名与追杀，只为让我能好好活。

### 核心反转
- 反转类型：动机反转 + 认知反转
- 反转内容：仇人不是仇人，是替罪与守护者；真正的屠手是失忆的「我」
- 误导假线索（让读者恨他）：江湖传言他为夺《渡劫刀谱》灭门；他逃命时带走了刀谱残页；门中长老临死咬定「是他」
- 铺垫真线索（≥3）：
  1. 他从不还手伤我要害，只逃、只挡、只卸力
  2. 「我」对那一夜只有空白，旁人细述屠门细节时我会偏头痛、反胃
  3. 他会用只有我师父教过的「青矾止血」
  4. 他怀里一直藏着与我刀柄上拼得上的另半截「渡」字刀穗

### 情绪设计
- 开头情绪：恨意冷锋（强度 8）——刀已抵喉，十年一偿
- 中段情绪：追与逃的拉扯 + 旧日结义暖意被「背叛」染色（强度 5→7）
- 反转情绪：真相砸下，恨无处落脚（强度 10，峰值维持第 9-10 节）
- 结尾情绪：意难平余韵（强度 8→6）——刀埋了，人没了，仇也没了
- 节奏：温暖（结义回忆）→ 残忍（屠门认知）→ 善意（他护我痕迹）→ 真相 → 来不及 → 释然细节暴击

### 人设速写
- 主角（沈渡）：渡劫门唯一幸存者，十年追杀成执念；刀快、话少、恨比命硬；失忆那一夜是心结
- 关键角色（顾衡）：昔日结义兄长，被全江湖指为屠门凶手；实际是替「我」背锅的人，逃了十年只为不让「我」知道自己杀了全家
- 关系：结义兄弟 → 仇人与仇家 → 真相后只剩一个活着的人
- 配角：
  - 柳三刀：赏金猎手，要拿顾衡人头换赏金与刀谱残页
  - 老仵作周伯：那夜唯一没死透的证人，前半程欲言又止

### 反派设计
- 本篇主「仇人」实为守护者，真正的「恶」是：
  1. 外敌：青城客（下迷药夺刀谱者）——前史反派，可在回忆/证词中出现，不必全程在场
  2. 现实压力：柳三刀（嚣张型）——小恶嘲讽 → 中恶抢功下毒手 → 大恶要当着沈渡的面斩顾衡
- 柳三刀：
  - 身份：赏金榜上的猎人，与沈渡抢「仇人」
  - 动机：贪婪（赏金 + 刀谱）
  - 作恶方式：堵截、羞辱、要当沈渡面行刑
  - 致命弱点：傲慢，低估顾衡与沈渡的旧情变数
  - 报应：死在自己要行刑的刀下（因果轮回：抢人头者丢命）

### 揭露方式
- 主用：证物揭露（半截刀穗合璧 + 顾衡怀里的那夜手札）+ 证人补刀（周伯临终/重伤吐真言）
- 辅用：延迟剥洋葱
  - 第 1 层（第 8 节）：顾衡不是为夺刀谱（假线索崩）
  - 第 2 层（第 9 节）：那夜动手的是「我」
  - 第 3 层（第 10 节）：他替我背锅十年，是结义时说过「渡你一劫」

### 题材招式（本篇选用）
- 情感/虐心：前 1/3 用物件与数字建羁绊（结义三年、追杀十年、一枚刀穗）
- 古言简洁：门派恩怨一笔带清，不铺大世界观
- 羁绊→撕裂→余韵钝痛：结义暖 → 屠门恨 → 真相来不及
- 开篇钩子：冲突前置（刀已抵喉）
- 结尾：余韵式 + 物件回扣

### 对标摘要
- 无对标拆文；按情感/虐心公式自建。

### 反转信息差验证
- 真相主揭示节：第 9 节；总节数 12；位置 ≈ 75%（>60%，合格）
- 假线索：夺刀谱灭门（贯穿前 8 节江湖议论与沈渡自我确信）
- 真线索分散：第 2/4/5/7 节；与揭穿间距 ≥ 3 节

### 伏笔回查
- 结尾元素：刀穗合璧、旧刀入土、顾衡之死、沈渡独活
- 铺垫：刀穗（1）/ 旧刀（1）/ 他不还手（2）/ 青矾止血（5）/ 失忆头痛（4）/ 「渡你一劫」旧话（3 回忆）
